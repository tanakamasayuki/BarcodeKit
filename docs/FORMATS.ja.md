# 対応形式リファレンス

> English: [FORMATS.md](FORMATS.md)

BarcodeKit が対応する形式ごとの、入力できる文字・桁数・チェックディジット・幅・推奨余白の一覧。

すべての形式で共通の使い方は [../README.ja.md](../README.ja.md) を参照。

## 一覧

| 形式 | クラス | 入力文字 | 桁数 | チェックディジット | 幅（モジュール） |
| --- | --- | --- | --- | --- | --- |
| Code 39 | `Code39` | `0-9 A-Z - . $ / + %` と空白 | 1〜 | 任意（mod 43） | `16 × (n+2) − 1` |
| Code 93 | `Code93` | Code 39 と同じ | 1〜 | 必須・常に自動（C/K） | `9 × (n+4) + 1` |
| Code 128 | `Code128` | ASCII 0〜127 | 1〜 | 必須・常に自動 | `11 × (s+2) + 13` |
| EAN-8 | `EAN8` | 数字 | 7 または 8 | 必須・自動または検証 | `67`（固定） |
| EAN-13 | `EAN13` | 数字 | 12 または 13 | 必須・自動または検証 | `95`（固定） |
| UPC-A | `UPCA` | 数字 | 11 または 12 | 必須・自動または検証 | `95`（固定） |
| UPC-E | `UPCE` | 数字 | 6 または 8 | 必須・自動または検証 | `51`（固定） |
| ITF | `ITF` | 数字 | 偶数桁 | 任意（mod 10） | `4 + 18 × (n/2) + 5` |
| ITF-14 | `ITF14` | 数字 | 13 または 14 | 必須・自動または検証 | `135`（固定） |
| Codabar | `Codabar` | `0-9 - $ : / . +`、start/stop は `A B C D` | 3〜 | 任意（mod 16） | 可変 |
| QR Code | `QRCode` | 任意のバイト列（UTF-8 可） | バージョンと誤り訂正レベル次第 | 不要（誤り訂正で担保） | `17 + 4 × version`（21〜177 の正方形） |

- `n` = 入力文字数、`s` = Code 128 の内部シンボル数（Code C では数字 2 桁が 1 シンボル）
- 幅は **narrow:wide = 3:1** のときの値。`setRatio(2)` にすると Code 39 は `13 × (n+2) − 1`、ITF は `4 + 14 × (n/2) + 4` になる
- 幅にクワイエットゾーンは含まない

## 推奨クワイエットゾーン

`quietLeft()` / `quietRight()` / `quietTop()` / `quietBottom()` で取得できる。単位はモジュール。

| 形式 | 左 | 右 | 上 | 下 |
| --- | --- | --- | --- | --- |
| Code 39 / Code 93 / Code 128 | 10 | 10 | 0 | 0 |
| EAN-13 | 11 | 7 | 0 | 0 |
| EAN-8 | 7 | 7 | 0 | 0 |
| UPC-A | 9 | 9 | 0 | 0 |
| UPC-E | 9 | 7 | 0 | 0 |
| ITF / ITF-14 | 10 | 10 | 0 | 0 |
| Codabar | 10 | 10 | 0 | 0 |
| QR Code | 4 | 4 | 4 | 4 |

**余白を省略すると読み取り性能が落ちる。** `BarcodeKitDraw.h` の描画ヘルパーは既定で余白を付ける。自分で描く場合は、この分だけ背景色の余白を確保すること。

## チェックディジットの扱い

### 任意の形式（Code 39 / ITF / Codabar）

既定では付けない。`setCheckDigit(true)` を呼ぶと計算して付加する。

### 必須の形式（Code 93 / Code 128）

規格上必須なので常に自動で付く。設定は不要。

### 自動または検証（EAN-8 / EAN-13 / UPC-A / UPC-E / ITF-14）

渡した桁数で動作が変わる。

| 渡す桁数 | 動作 |
| --- | --- |
| 本体桁数（EAN-13 なら 12 桁） | チェックディジットを計算して付加する |
| 全桁（EAN-13 なら 13 桁） | 検証し、合わなければ `CheckDigitMismatch` を返す |

検証をやめたい場合は `setVerifyCheckDigit(false)` を呼ぶ。全桁を渡してもそのまま使う。

最終的なデータ（チェックディジット込み）は `text()` で取れる。

## 形式ごとの注意

### Code 39

- start/stop の `*` はライブラリが付ける。**入力に `*` を含めない。**
- 小文字はエラーになる。`setUppercase(true)` を呼ぶと自動で大文字に変換する。
- Full ASCII モード（`+A` などで小文字や記号を表す拡張）は非対応。

### Code 93

- Full ASCII モードは非対応。

### Code 128

- コードセット A / B / C はシンボル数が最小になるよう自動で切り替える。数字が 4 桁以上並べば Code C を使う。
- 明示したい場合は `setCodeSet(CodeSet::A)` などを呼ぶ。
- GS1-128（FNC1 を使うもの）は非対応。

### EAN / UPC

- ガードバー（左端・中央・右端）はデータバーより下へ伸ばすのが正しい表示。`barExtends(x)` が `true` を返す列がそれで、描画ヘルパーは既定で 5 モジュール分伸ばす。
- UPC-E のナンバーシステムは 0 または 1 のみ。
- アドオン（EAN-2 / EAN-5）は非対応。

### ITF / ITF-14

- ITF は偶数桁が必須。奇数桁はエラーになる。`setPadOdd(true)` を呼ぶと先頭に `0` を補う。
- ITF-14 はベアラバー（囲み枠）を付けるのが一般的なので、描画ヘルパーでは既定で付く。

### Codabar

- start/stop 文字（`A` `B` `C` `D`）を**入力に含める**。例: `"A12345A"`。
- 含めずに使いたい場合は `setAutoStartStop(true)` を呼ぶと `A`/`A` が自動で付く。

### QR Code

| 設定 | 既定 | 説明 |
| --- | --- | --- |
| `setEcc(Ecc::L\|M\|Q\|H)` | `M` | 誤り訂正レベル。高いほど汚れに強いが容量が減る |
| `setVersionRange(min, max)` | `1, 40` | 使うバージョンの範囲。バッファに収まらない上限は自動で下がる |
| `setMask(Mask::Auto \| 0..7)` | `Auto` | マスクパターン。通常は変更不要 |
| `setBoostEcc(bool)` | `true` | 同じバージョンに収まるなら誤り訂正レベルを自動的に上げる |

- 数字 / 英数字 / バイト（UTF-8）モードは自動で選ばれる。
- **漢字モードは非対応。** 日本語は UTF-8 のバイト列として符号化されるため表示・読み取りはできるが、漢字モードより容量効率は落ちる。
- 入力が入りきらない場合は `CapacityExceeded` を返す。誤り訂正レベルを下げるか、バッファを大きくする。

## 必要なバッファサイズ

`bufferSize()` はコンパイル時に計算できる。

```cpp
uint8_t buf1[BarcodeKit::EAN13::bufferSize()];        // 固定長の形式は引数なし
uint8_t buf2[BarcodeKit::Code128::bufferSize(20)];    // 入力20文字まで
uint8_t buf3[BarcodeKit::QRCode::bufferSize(10)];     // バージョン10まで
```

1次元の実値（実装で確定済み）:

| 形式 | `bufferSize()` |
| --- | --- |
| EAN-13 / UPC-A | 12 バイト |
| EAN-8 | 9 バイト |
| UPC-E | 7 バイト |
| Code 128（入力20文字） | 60 バイト |

シンボルのオブジェクト自体は 64 バイト（うち 49 バイトが `text()` 用）。`BARCODEKIT_TEXT_MAX` を小さくすると減らせる（16 にすると 32 バイト）。

QR の目安（実値は実装で確定する）:

| 最大バージョン | 一辺 | バッファ |
| --- | --- | --- |
| 10 | 57 | 約 0.7 KB |
| 20 | 97 | 約 2.2 KB |
| 40 | 177 | 約 7.1 KB |

AVR（Uno、RAM 2 KB）では QR はバージョン 10 前後が上限になる。1次元形式はどれも数十バイトで足りる。

## 対応していない形式

初期リリースでは以下に対応しない。将来の追加候補としている。

- Data Matrix / PDF417 / Aztec Code
- GS1-128 / GS1 DataMatrix / GS1 QR Code
- Code 39・Code 93 の Full ASCII モード
- EAN-2 / EAN-5 アドオン
- QR の漢字モード
